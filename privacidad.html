Información sobre el formulario de contacto de esta vista previa.

Qué datos se usan

El formulario utiliza tu nombre, teléfono y los datos del proyecto que decidas compartir para preparar una consulta dirigida a PROJECTCONS. No pide documentos de identidad, datos bancarios ni archivos.

Cuándo se comparten

El resumen se prepara en tu navegador. No se guarda en una base de datos de este sitio ni se envía automáticamente. Solo al pulsar «Abrir WhatsApp» se transfiere el texto a ese servicio; tú confirmas el envío dentro del chat. WhatsApp se rige por su propia política de privacidad.

Contacto y seguimiento

PROJECTCONS recibirá únicamente lo que envíes por WhatsApp para atender tu consulta y conversar sobre tu proyecto. Para solicitar aclaraciones o dejar de recibir seguimiento, comunícate al +52 612 136 3583.

Servicios externos

El alojamiento es GitHub Pages. Las tipografías se cargan desde Google Fonts. Los enlaces de créditos llevan a Pexels. No hemos incorporado herramientas de analítica ni píxeles publicitarios. Esos proveedores pueden procesar datos técnicos al cargar sus recursos o visitar sus enlaces.

Versión de revisión: el responsable del negocio debe validar y completar su aviso de privacidad definitivo antes del lanzamiento comercial. Este texto describe el funcionamiento actual; no sustituye esa revisión.
